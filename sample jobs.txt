I run an ecommerce business selling high-ticket wellness equipment. I need an experienced n8n developer to build a lead automation system connecting OpenPhone, Gmail, Notion, Shopify, and the Claude API.

THE DESIGN WORK IS DONE.

You'll receive a complete build brief (~380 lines) specifying every workflow, database schema, matching rule, message template, and edge case. Your job is implementation, not discovery. The brief includes a suggested build order with 5 milestones.

I've attached a system flowchart showing how the whole build fits together. The full brief is shared with shortlisted candidates.

WHAT YOU'LL BUILD (on n8n Cloud):

1. Notion setup + migration — consolidate two existing lead tables into one, add fields per the provided schema (one-time)

2. Call & email intake — OpenPhone call-completed and Gmail triggers → one LLM step (Claude API) classifies each call/email (new lead / support / spam) and extracts structured fields → creates/updates rows in the right Notion table, with dedup by phone/email

3. Follow-up engine — scheduled sequence (4 touches: SMS via OpenPhone, email via Gmail) with state-based message branching, exact send times with timezone handling, message tagging, pause-on-customer-reply, reset-on-owner-outbound with Gmail thread capture, and 5-day auto-resume. This is the most intricate flow; the tagging/detection logic is fully specified.

4. Shopify listeners — order-paid → flip lead status + create supplier tracker row; fulfillment-created → sync tracking number + status

5. Supplier watchdog + support alerts — daily business-day-aware check with per-product thresholds → alert digest to me; per-issue SMS alerts and a stale-issue nudge on the support table

STACK: n8n Cloud, Notion API, Shopify webhooks, Gmail API, OpenPhone API, Anthropic (Claude) API for classification/extraction/composition steps.

VOLUME IS SMALL (3–5 leads/day) — this is about reliability and correct edge-case handling, not scale.

HOW WE'LL WORK: 
Milestone-based, following the build order above. I review and test each milestone before the next begins. I'm responsive and the spec answers most questions, but I'm available for the ones it doesn't.

TO APPLY, PLEASE ANSWER:

1. Have you built n8n workflows that call an LLM API for classification with structured JSON output? Describe one briefly.

2. Have you worked with the Notion API (create/update/query databases)?

3. Have you handled Gmail send/reply threading in an automation (replying within an existing thread programmatically)?

4. What's your approach to preventing an automated follow-up from firing after a human has manually replied in a thread?

5. Rough estimate: hours for the 5 milestones above, assuming a complete spec.
